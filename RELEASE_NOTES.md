# Release Notes — v1.1.0

Опис змін у версії **v1.1.0** порівняно з **v1.0.0**.

## Added
- Додано спеціальний базовий тариф доставки `80.0` для міста `"Kyiv"`.
- Додано явний параметр ставки податку `tax_rate` у функції розрахунку.

## Changed
- Коефіцієнт вартості доставки за кілограм ваги збільшено з `12.0` до `15.0`.
- Виконано рефакторинг модуля білінгу з переходом до слабкого зв'язування (**Data Coupling**).

## Breaking Changes
- Змінено сигнатури функцій розрахунку (передаються лише необхідні примітивні параметри замість цілого об'єкта профілю клієнта).
- Видалено спільну глобальну змінну `GLOBAL_TAX_RATE` (усунуто *Common Coupling*).
- Видалено керуючий прапорець `mode_flag` (усунуто *Control Coupling*).
